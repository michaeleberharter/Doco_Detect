# Schrift zu klein / Fenster passt nicht

Symptom: Die Oberfläche ist zu klein zum Lesen — oder das Fenster ragt
über den Bildschirm hinaus (untere Leiste abgeschnitten). Eventuell
erschien beim Start kurz eine Hinweisbox „UI-Skalierung“.

## Was ist los?

Die UI-Skalierung ist eine Einstellung (Zahnrad → Darstellung). Sie
wirkt erst nach einem Neustart der App — der Dialog kennzeichnet das
und weist beim Schließen darauf hin. Angeboten werden nur Stufen, die
auf den aktuellen Bildschirm passen; ist ein größerer Wert gespeichert
(etwa von einem größeren Monitor), sagt der Dialog das ausdrücklich.
Beim Start wird eine zu große gespeicherte Stufe automatisch begrenzt —
die gespeicherte Einstellung bleibt dabei erhalten und gilt wieder,
sobald die Station an einem größeren Bildschirm hängt. Die
Start-Hinweisbox erklärt genau diese Fälle und schließt sich von
selbst.

## Was tun?

- 🟢 **GRÜN** — Zahnrad → Darstellung → „UI-Skalierung“: passende Stufe wählen, dann App neu starten.
- 🟢 **GRÜN** — Ragt das Fenster über den Bildschirm hinaus: kleinere Stufe wählen und neu starten — oder das Fenster auf den größeren angeschlossenen Bildschirm ziehen, falls einer verbunden ist.
- 🟢 **GRÜN** — Im selben Dialog liegen auch Theme (Hell/Dunkel/System) und die Ergebnis-Standzeit; der Touch-Modus (größere Trefferflächen, kinetisches Scrollen) unter „Bedienung“ — seine Bildschirmtastatur wirkt ebenfalls erst nach Neustart.
- 🟡 **GELB** — App neu starten, damit Skalierungs-Änderungen wirksam werden.
